A compact, VS Code-style git source-control sidebar in the left drawer, over the git installed in the Linux runtime. Authored in TypeScript and built for production.

Detects the real repository root(s) — in a User Workspace it enumerates every project folder and lets you switch between repositories. View working-tree changes as a flat list or a folder tree; the Staged and Changes sections collapse. Stage / unstage / discard inline, commit staged changes (with an inline identity form the first time), switch and create branches, and fetch / pull / push with automatic upstream setup for new branches.

Sign in to GitHub with a Personal Access Token — stored via git's credential helper so push/pull to GitHub HTTPS remotes just work — and set an origin remote from the panel.

Decorates the app's file explorer with per-file git status letters and submodule markers, and adds an "Add to .gitignore" entry to the explorer's file/folder menu. Follows JCode's theme tokens so it matches the app. Offers to initialize a repository when the open project isn't one yet.
